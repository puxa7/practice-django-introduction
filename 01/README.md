# `#01` Django: Wprowadzenie

1. Utwórz nowy katalog na projekt Django i przejdź do niego w terminalu.
2. W tym katalogu utwórz i aktywuj nowe środowisko wirtualne
3. Zainstaluj Django w aktywnym środowisku:
4. Utwórz nowy projekt Django poleceniem:
5. Przejdź do katalogu projektu:
6. Uruchom serwer developerski:
7. Wejdź w przeglądarce na adres http://127.0.0.1:8000/ i upewnij się, że widzisz stronę powitalną Django z rakietą.
8. Otwórz plik `settings.py`, znajdź zmienną `TIME_ZONE` i zmień jej wartość na:


TIME\_ZONE = "Europe/Warsaw"


9. Zrestartuj serwer (przerwij działanie Ctrl+C i uruchom ponownie `python manage.py runserver`), aby sprawdzić, czy projekt działa poprawnie po zmianie konfiguracji.

**Wskazówka:**
Zwróć uwagę na poprawne działanie środowiska wirtualnego – jeśli napotkasz błąd „django-admin: command not found”, oznacza to, że środowisko nie zostało aktywowane.
