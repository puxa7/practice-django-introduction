# `#02` Django: Wprowadzenie


1. W katalogu projektu utwórz nową aplikację.
2. Dodaj aplikację do listy `INSTALLED_APPS` w pliku `settings.py`.
3. W pliku widoków swojej aplikacji stwórz widok funkcyjny, który zwraca prosty tekst „To mój pierwszy widok w Django!”.
4. Skonfiguruj routing w projekcie tak, aby widok był dostępny pod adresem `/hello/`.
5. Otwórz w przeglądarce adres http://127.0.0.1:8000/hello/ i sprawdź, czy wyświetla się odpowiednia wiadomość.

**Wskazówka:**
Pamiętaj, aby aplikacja była zarejestrowana w `INSTALLED_APPS`, inaczej Django jej nie rozpozna.
